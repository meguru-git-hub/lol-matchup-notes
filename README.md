# LoL マッチアップノート

League of Legends の自分専用マッチアップノート。
自分のチャンプ × 相手のチャンプ ごとに、対面で気をつけることをメモして残せます。

**公開URL: https://meguru-git-hub.github.io/lol-matchup-notes/**

## 機能

- 自分のチャンプと相手のチャンプを選べる（日本語名・英語名どちらでも検索可）
- マッチアップごとに4項目のメモを保存
  - ⚠️ 避けるべきスキル
  - ⚔️ トレードしていいタイミング
  - 📈 相手のパワースパイク
  - 💭 ひとこと反省
- 保存済みマッチアップの一覧表示・編集・削除

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | ページの骨組み（どこに何があるか） |
| `style.css` | 見た目（色・大きさ・並べ方） |
| `app.js` | 動き（データ取得・選択・保存） |

HTML・CSS・JavaScript だけで作られています。ビルド作業もライブラリも不要です。

## メモの保存場所

メモはブラウザの **localStorage** に保存されます。つまり:

- メモは**自分のブラウザの中だけ**に保存され、ネット上には一切アップロードされません
- このリポジトリを公開していても、メモの中身は誰にも見えません
- 端末やブラウザを変えると、メモは引き継がれません
- ブラウザの「サイトデータを削除」をするとメモも消えます

## チャンピオンのデータについて

チャンピオン一覧と画像は Riot Games の [Data Dragon](https://developer.riotgames.com/docs/lol#data-dragon)
から毎回取得しています。最新バージョンを自動で調べているので、新チャンピオンが追加されても
コードを直す必要はありません。表示にはインターネット接続が必要です。

## ローカルで動かす

`index.html` をブラウザで開くだけです（サーバー不要）。
