# LoL マッチアップ対策シート

チャンプセレクトで相手が決まった瞬間に開いて、**レーン戦をどう戦うか**をその場で確認するための
自分専用カンペ。試合後の振り返りノートではなく、**試合前の確認用**。

**公開URL: https://meguru-git-hub.github.io/lol-matchup-notes/**

## 使いかた

1. 最初に一度だけ「自分のチャンプ」を設定する（以降は記憶される）
2. 相手の名前を入力して **Enter** → 対策シートがすぐ出る
3. 上から順に読む。3秒で「方針」、15秒で「避ける／仕掛ける／危険な時間帯／ビルド」

## 画面の作り

読む順番＝大事な順番になるように並べている。

| 場所 | 内容 |
|---|---|
| 相性バッジ | 有利 / 互角 / 不利 / 超不利 を色で即判断 |
| レーン戦の方針 | ひとことだけ。一番大きく表示される |
| ⚠️ 絶対に避ける | 踏んだら負ける行動・スキル |
| ⚔️ 仕掛けていいとき | トレードして良い条件 |
| ⏰ 相手が強くなる瞬間 | パワースパイク（レベル・アイテム・スタック） |
| 🛡️ ビルド・ルーン対策 | 何を積むか、何を持つか |
| 🕐 レーン戦の流れ | Lv1-2 / Lv3-5 / Lv6+ ごとの動き（折りたたみ） |
| 📖 相手のスキル | Data Dragon から**自動表示**。QWERの名前とクールダウン |
| 📝 気づいたこと | 試合後に足す用（折りたたみ） |

「相手のスキル」だけは自分で書く必要がない。Data Dragon から毎回取得している。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | ページの骨組み（どこに何があるか） |
| `style.css` | 見た目（色・大きさ・並べ方） |
| `app.js` | 動き（データ取得・選択・表示・保存） |

HTML・CSS・JavaScript だけ。ビルド作業もライブラリも不要。

## メモの保存場所

対策はブラウザの **localStorage** に保存される。つまり:

- 対策は**自分のブラウザの中だけ**に保存され、ネット上には一切アップロードされない
- このリポジトリを公開していても、書いた対策の中身は誰にも見えない
- 端末やブラウザを変えると引き継がれない
- ブラウザの「サイトデータを削除」をすると対策も消える

保存に使っているキーは2つ。

| キー | 中身 |
|---|---|
| `lolMatchupNotes` | マッチアップごとの対策（`Yasuo_vs_Darius` のような名前で区別） |
| `lolMyChampion` | 自分のチャンプ |

## チャンピオンのデータについて

チャンピオン一覧・アイコン・スキル情報は Riot Games の
[Data Dragon](https://developer.riotgames.com/docs/lol#data-dragon) から取得している。
最新バージョンを自動で調べているので、新チャンピオンが追加されてもコードを直す必要はない。
表示にはインターネット接続が必要。

## ローカルで動かす

`index.html` をブラウザで開くだけ（サーバー不要）。
