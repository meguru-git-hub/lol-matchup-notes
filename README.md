# LoL ガイド

League of Legends の自習ノート。チャンプセレクトで使う**マッチアップ対策シート**と、
ロール・マクロ・アイテムなどの**解説記事**を置いている。

**公開URL: https://meguru-git-hub.github.io/lol-matchup-notes/**

## ページ構成

| URL | 中身 |
|---|---|
| `/` | トップページ（入口と記事の一覧） |
| `/matchup.html` | マッチアップ対策シート |
| `/guide.html?cat=macro` | その分類の記事一覧 |
| `/guide.html?id=wave-basics` | 記事そのもの |

## 記事の足しかた

`articles.js` の `ARTICLES` に `{ ... }` をひとつ足すだけ。
足せばトップページにも分類ページにも自動で並ぶ。

```js
{
  id:      "top-role",        // URL に使う名前（半角英数とハイフン）
  cat:     "role",            // 分類。CATEGORIES の id のどれか
  title:   "TOPレーンの役割",
  summary: "一覧に出る1〜2行の説明",
  updated: "2026-10-01",
  body: [
    { h: "見出し" },
    { p: "段落。配列にすれば複数段落" },
    { list: ["箇条書き1", "箇条書き2"] },
    { note: "目立たせたい補足" },
    { table: { head: ["列1","列2"], rows: [["a","b"]] } }
  ]
}
```

文章の中で `**ここ**` のように `*` を2つで囲むと、その部分が金色で強調される。

分類そのもの（ロール解説・マクロ解説など）を増やしたいときは、
同じ `articles.js` の `CATEGORIES` に足して、`nav.js` の `NAV_ITEMS` にも1行足す。

## マッチアップ対策シート

チャンプセレクトで相手が決まった瞬間に開いて、**レーン戦をどう戦うか**をその場で確認する。
試合後の振り返りノートではなく、**試合前の確認用**。

### 使いかた

1. 最初に一度だけ「自分のチャンプ」を設定する（以降は記憶される）
2. 相手を選ぶ。探しかたは2通り
   - 名前を入力して **Enter**（区切り文字は省略可。「ミスフォーチュン」「カイサ」でも出る）
   - **あ行〜わ行**のタブで絞りこむ
3. 上から順に読む。3秒で「方針」、15秒で「避ける／仕掛ける／危険な時間帯／対策」

### 画面の作り

| 場所 | 内容 | 自分で書く？ |
|---|---|---|
| 相性バッジ | 有利 / 互角 / 不利 / 超不利 を色で即判断 | 書く |
| レーン戦の方針 | ひとことだけ。一番大きく表示される | 書く |
| ⚠️ 絶対に避ける | 踏んだら負ける行動・スキル | 書く |
| ⚔️ 仕掛けていいとき | トレードして良い条件 | 書く |
| ⏰ 相手が強くなる瞬間 | パワースパイク（レベル・アイテム・スタック） | 書く |
| 🛡️ 対策メモ | 立ち回りの注意 | 書く |
| ルーン / ビルド | 本物のアイコンで表示。チャンピオンごとの「基本形」を登録すると、新しいマッチアップに自動で引き継がれる | 選ぶ |
| 🕐 レーン戦の流れ | Lv1-2 / Lv3-5 / Lv6+（折りたたみ） | 書く |
| 📖 スキル | **相手／自分をタブで切り替え**。名前・クールダウン・効果の説明・動画。用語はゲームと同じ色分け | **自動** |
| チャンピオンの特徴 | 分類（ファイター等）と攻撃/防御/魔法/難度の目安 | **自動** |
| 📝 気づいたこと | 試合後に足す用（折りたたみ） | 書く |
| op.gg / u.gg リンク | 最新の統計を外部サイトで見る | 自動 |

## データの出どころ

すべて Riot Games の公開データを使っている。APIキーもサーバーも不要。

| 内容 | 取得元 |
|---|---|
| チャンピオン一覧・アイコン | Data Dragon `champion.json` |
| スキル名・クールダウン・効果説明 | Data Dragon `champion/{名前}.json` |
| スキル動画 | Riot CDN `champion-abilities/{4桁の番号}/ability_*.webm` |
| ルーン（全系統・キーストーン） | Data Dragon `runesReforged.json` |
| アイテム（全種・アイコン） | Data Dragon `item.json` |

バージョンは毎回自動で最新を調べているので、新チャンピオンやアイテム変更があっても
コードを直す必要はない。表示にはインターネット接続が必要。

### 「おすすめビルド」を自動表示しない理由

op.gg や u.gg が出している勝率ベースのおすすめビルドは、**このサイトからは取得できない**。

- それらのサイトに公開APIが無く、ブラウザから直接読むのは CORS で塞がれている
- Riot 公式APIで自分で集計するにはAPIキーが必要だが、静的サイトだとキーがソースに
  書かれて全員に見えてしまう（＝すぐ失効する）

なので**ルーンとビルドは自分で選んで保存する方式**にしている。さらに、毎回ゼロから選ばなくて
済むよう、チャンピオンごとに**「基本形」**を1つ登録できる。基本形は対策を書いていない
マッチアップにも自動で表示され（`基本形` の印がつく）、編集画面では下書きとして入る。
最新の統計を見たいときのために op.gg / u.gg へのリンクを置いてある。

### スキル説明文のタグについて

Riot の説明文には `<magicDamage>魔法ダメージ</magicDamage>` `<br>` のようなタグが
埋めこまれている（173体中85体、860スキル中166件）。そのまま表示すると `</font>` のような
記号が見えてしまうので、`<br>` は改行にし、その他のタグは消したうえで中の文字を
ゲーム本編と同じように色分けしている。

## 保存されるもの

ブラウザの **localStorage** に保存される。つまり:

- **自分のブラウザの中だけ**に保存され、ネット上には一切アップロードされない
- このリポジトリを公開していても、書いた対策の中身は誰にも見えない
- 端末やブラウザを変えると引き継がれない
- ブラウザの「サイトデータを削除」をすると対策も消える

| キー | 中身 |
|---|---|
| `lolMatchupNotes` | マッチアップごとの対策（`Yasuo_vs_Darius` のような名前で区別） |
| `lolMyChampion` | 自分のチャンプ |
| `lolChampionBasics` | チャンピオンごとの基本ルーン・基本ビルド |
